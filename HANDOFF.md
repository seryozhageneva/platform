## Известные проблемы и подводные камни

- Тесты фронтенда, проверяющие вызовы API после `setState`, могут «плавать» на медленной машине CI: повторный запрос делает эффект React уже после отрисовки. Такие проверки оборачивать в `vi.waitFor`.
- Для ручных запусков нужны два процесса: `uv run python -m backend.api` и `uv run arq backend.triggers.worker.WorkerSettings`. Если в журнале запуска только `run_queued` — рабочий процесс не запущен или не видит Redis (ADR 0022).
- Автоматического восстановления зависших запусков нет (ADR 0022).
- На origin остались ветки уже слитых задач 12–17 и 18a. Удалять — только с разрешения автора.
