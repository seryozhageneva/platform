## Требует сверки с Codex

- **Хук.** Локальные `.codex/hooks.json` и исполняемый `.codex/hooks/format.sh` на месте и игнорируются Git. В пользовательском конфиге есть запись доверия для этого хука. По [документации Codex](https://learn.chatgpt.com/docs/hooks) `Edit|Write` подходит для `apply_patch`. Пробный запуск скрипта с JSON события Codex (`tool_input.command`, текстовый `tool_response`) показал, что скрипт не получает путь к файлу и выходит с кодом 0 до форматирования. Автоматический вызов в этой сессии отдельно не подтверждён.
- **Ревьюер.** Файл `.codex/agents/reviewer.toml` читается, а роль `reviewer` с его описанием доступна в текущей сессии. Этого достаточно, чтобы подтвердить распознавание конфигурации. Пробное ревью не запускалось.
- **Скилл.** `.agents/skills/next-task/SKILL.md` читается, и `next-task` виден в списке доступных скиллов. Поддержка `disable-model-invocation`, `argument-hint` и автоматической подстановки `$ARGUMENTS` в этой сессии не подтверждена. Для запрета автоматического вызова [документация Codex](https://learn.chatgpt.com/docs/build-skills) описывает `policy.allow_implicit_invocation: false` в `agents/openai.yaml` внутри скилла. Скилл для планирования задачи 19 не запускался.
