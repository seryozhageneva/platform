# Задача 20. Конспект и задачи по лекции

Замер от 11.11.2026, модель GigaChat-2. Три выдуманные мини-лекции: сложение
дробей, площадь и периметр прямоугольника, среднее арифметическое.
Для каждой лекции блок запросил конспект и две задачи. Конспект был
дополнительным входом для генерации задач.

```sh
uv run --no-sync python -m experiments.ai_process_eval
```

Скрипт проверил форму через рабочий блок. Правила и примеры в конспектах
сверены с лекциями вручную. Ответы к задачам пересчитаны по их условиям.

## Результат с итоговыми шаблонами

| Лекция | Форма конспекта | Форма списка задач | Верных ответов | Конспект и задачи |
| --- | --- | --- | --- | --- |
| Дроби | Прошла, 1036 мс | Прошла, 1386 мс | 2 из 2 | Конспект назвал тему и термины, пропустил само правило и пример. Ответы `8/8` и `6/9` верны. |
| Прямоугольник | Прошла, 806 мс | Прошла, 1422 мс | 2 из 2 | Конспект передал обе формулы и пример. Ответы `10` и `18` верны. |

Проверку формы прошли **6 из 6** ответов. Верных эталонов **5 из 6**.
Пример расчёта из лекции сохранился в **1 из 3** конспектов.

В первом прогоне форма также прошла в 6 из 6 ответов. Для прямоугольника
модель выдала несколько величин с пояснениями в одном эталоне, а для среднего
арифметического округлила оба результата. Шаблон уточнили: один числовой
ответ, без округления и единиц. В повторном прогоне все ответы записаны
числом или дробью, но один расчёт остался неверным. Эта ошибка прошла
проверку формы и обнаружилась при пересчёте по условию.
