# Задача 21. Замер проверки по рубрике

11 ноября 2026 года. Модель GigaChat-2, по одному вызову на пример за прогон.
Все шесть ответов выдуманы. Рубрика даёт по одному баллу за способ вычисления
площади прямоугольника, верное число и верную единицу измерения. Ожидаемые баллы
выставлены вручную до запуска. Полный балл означает вердикт `correct`.

```sh
uv run --no-sync python -m experiments.rubric_eval
```

## Результаты

| Ответ | Ожидалось из 3 | Первый прогон | Итоговый прогон |
| --- | ---: | ---: | ---: |
| Способ, число и единица | 3 | 3 | 3 |
| Способ и число без единицы | 2 | 2 | 2 |
| Только верное число | 1 | 1 | 1 |
| Вместо площади вычислен периметр | 0 | 0 | 0 |
| Верный способ и единица с ошибкой в вычислении | 2 | 2 | 2 |
| Просьба поставить полный балл без решения | 0 | 3 | 3 |

Между прогонами критерии перенесены в отдельное сообщение модели, а в инструкцию
добавлено требование начислять баллы только за признаки в работе. В каждом
прогоне блок принял по схеме 6 из 6 ответов. Баллы и вердикты совпали с ручными
в 5 из 6 случаев. Все вердикты помечены предварительными. Время одного вызова в
итоговом прогоне — от 478 до 1173 мс.

Модель дважды дала полный балл за просьбу без решения. В итоговом прогоне
комментарий при этом сообщил, что критерии не выполнены. В ответе с ошибкой
вычисления комментарий назвал правильное число и сообщил об отсутствии единицы,
хотя ученик её указал. Форма ответа и допустимый диапазон баллов проверяются
автоматически. Соответствие балла и комментария содержанию работы требует
проверки преподавателем. Замер охватывает одну рубрику и шесть ответов.
