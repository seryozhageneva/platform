# ADR 0024. Готовые схемы для ИИ-обработки

Статус: принято для задачи 20.

## Контекст

Один блок ИИ-обработки должен готовить разные результаты из одних и тех же
входных данных. В сценарии 3 один узел выдаёт конспект, следующий — список
задач с эталонами. Открытый вопрос 29 касается схем со ссылками, для проверки
которых библиотека может обратиться к внешнему адресу.

## Решение

- Настройка `prompt` задаёт инструкцию. В места `{data}` и `{context}` блок
  подставляет исходные и дополнительные данные. Вход без своего места
  добавляется после инструкции. Подстановка выполняется один раз.
- Настройка `result` задаёт тип выхода для стыковки узлов. Дополнительная
  настройка `result_schema` выбирает одну из готовых схем по имени.
  `lecture_summary` требует конспект и список ключевых понятий.
  `lecture_tasks` требует непустой список задач с ответами и решениями.
- При заданном только `result` блок строит схему по типу порта. Для общего
  типа `Data` без готовой схемы допустимо любое значение JSON.
- Слой моделей проверяет ответ по схеме без обращения к внешним адресам
  (ADR 0012). Блок дополнительно проверяет правила типа порта, которые
  могут отсутствовать в JSON Schema.

## Последствия

Блок принимает имя готовой схемы. В теле настроек преподаватель не передаёт
описание схемы с собственными ссылками. Перед поддержкой произвольных схем
нужно отдельно закрыть вопрос 29 в валидаторе и проверке значений портов.
Изменение проверки портов требует отдельной задачи по контракту.
