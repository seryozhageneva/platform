# ADR 0002. Стек технологий

- **Статус:** принято
- **Дата:** 11.10.2026

## Контекст

Платформу за 12 недель делает один человек, который не программист: код пишет Claude Code, автор читает и одобряет. Проект должен быть объясним на защите и работать на одном недорогом сервере в России. Подробное описание — в `docs/vision.md`, раздел «Стек и структура репозитория».

Отсюда три требования к стеку: как можно меньше разных технологий; технологии, которые Claude Code хорошо знает; ничего, что требует отдельной команды для обслуживания.

## Варианты

**Движок графа.** Готовый (LangGraph как исполнитель всего пайплайна, Temporal) или свой. Готовый движок диктует формат хранения и скрывает логику, которую нужно описывать в записке. Свой — несколько сотен строк, прозрачен и полностью объясним.

**Конструктор целиком.** Взять n8n, Dify или Flowise и дописать блоки. Быстрее на старте, но тогда главный результат работы — контракт блока и движок — оказывается чужим.

**Язык бэкенда.** Python или TypeScript на обеих сторонах. В Python живут библиотеки, без которых проекту не обойтись: SymPy, LangGraph, официальный SDK MCP.

**Очередь задач.** Celery или arq. Celery мощнее, но тяжелее в настройке; arq работает на том же Redis, поддерживает async и расписание.

## Решение

| Слой | Выбор | Почему |
| --- | --- | --- |
| Бэкенд | Python 3.12, FastAPI, Pydantic | Pydantic одновременно описывает контракт блока и проверяет данные; FastAPI сам строит OpenAPI-схему для фронтенда |
| База | PostgreSQL, SQLAlchemy, Alembic | Одна надёжная база на всё: пайплайны, запуски, журнал событий |
| Фоновые задачи | Redis + arq | Очередь и расписание без отдельного планировщика |
| Движок графа | Свой исполнитель | Прозрачен, не диктует формат хранения, описывается в записке |
| Агенты | LangGraph внутри блоков | Готовый инструмент там, где он уместен: цикл «подсказка — контролёр» |
| Внешние системы | MCP (официальный Python SDK), HTTP для простых сервисов | Один адаптер служит и блоку, и агенту; модели обучены работать с MCP |
| LLM | Свой слой провайдеров | Модель меняется настройкой; в тестах — фейковая модель |
| Математика | SymPy, latex2sympy2 | Проверка ответа без ИИ, детерминированно |
| Фронтенд | React, TypeScript, Vite, React Flow | React Flow — готовый редактор схем; типы приходят из OpenAPI |
| Инфраструктура | Docker Compose, GitHub Actions | Одна команда поднимает всё и на ноутбуке, и на сервере |
| Инструменты | uv, pnpm, ruff, pytest | Быстрые и без лишней настройки |

## Последствия

- Проще: один язык на бэкенде, одна база, одна команда запуска; всё знакомо Claude Code.
- Свой движок означает, что паузы, циклы и «для каждого» пишем и тестируем сами — это задачи 04 и 05. Взамен получаем главу записки и полный контроль.
- LangGraph остаётся зависимостью только агентных блоков: ядро о нём не знает, и его можно заменить, не трогая движок.
- Два языка в проекте (Python и TypeScript) связаны автоматически сгенерированным клиентом API: бэкенд поменял поле — фронтенд не соберётся, пока его не обновят.
- Docker Compose не масштабируется на много серверов. Для пилота и защиты это не нужно; в записке указывается как ограничение.
- Граница между MCP и HTTP пока проведена предварительно и уточняется после первых адаптеров — см. `docs/open-questions.md`, вопрос 11.
